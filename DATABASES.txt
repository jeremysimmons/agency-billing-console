AIB database schema (PostgreSQL) — slim ClickUp billing prep
Source: Script0001_Foundation.sql, Script0005_ClientOriginalName.sql, Script0006_SlimClickUp.sql
Enum-like columns stored as text (PascalCase, matching C# enums).
PK = primary key · FK = foreign key · UQ = unique · * = nullable

Auth tables may still exist from Script0001 but are unused (no login).

================================================================================
OVERVIEW
================================================================================

  agency ──┬── client ──┬── project   (you define)
           │            └── task      (ClickUp sync + manual prep cols)
           │
           └── last_clickup_sync_*

  clickup_container   (space / folder / list lookup; refreshed on sync)
