AIB database schema (PostgreSQL)
Source: backend/Aib.Infrastructure/Migrations/Script0001_Foundation.sql,
         Script0005_ClientOriginalName.sql
Enum-like columns stored as text (PascalCase, matching C# enums).
PK = primary key · FK = foreign key · UQ = unique · * = nullable

================================================================================
OVERVIEW
================================================================================

  agency ──┬── client ──┬── project
           │            └── task ──── task (parent)
           │
           ├── app_user ──┬── user_role ── role   (agency | contractor)
           │              ├── local_credential
           │              ├── magic_link_token
           │              ├── social_identity ── identity_provider
           │              └── user_session ── identity_provider
           │
           └── contractor ── app_user

2. IDENTITY & AUTH  (Script0001)
================================================================================

┌─────────────────────────────┐       ┌─────────────────────────────┐
│ agency                      │       │ contractor                  │
└──────────────┬──────────────┘       └──────────────┬──────────────┘
               │ *                                   │ *
               │                                     │
┌──────────────▼─────────────────────────────────────▼──────────────┐
│ app_user                                                          │
│───────────────────────────────────────────────────────────────────│
│ PK  id                       uuid                                 │
│ FK* agency_id                → agency                             │
│ FK* contractor_id            → contractor                         │
│     username / normalized_username   UQ(normalized_username)      │
│     email / normalized_email         UQ(normalized_email)         │
│     display_name, status                                          │
│  *  email_verified_at, last_login_at                              │
│     password/magic_link/social_login_enabled                      │
│     created_at / updated_at                                       │
└──┬────┬────┬────┬────┬────────────────────────────────────────────┘
   │    │    │    │    │
   │    │    │    │    └───────── user_session
   │    │    │    │                   FK  user_id
   │    │    │    │                   FK* identity_provider_id
   │    │    │    │                   UQ  session_token_hash
   │    │    │    │
   │    │    │    └────────────── social_identity
   │    │    │                        FK  user_id
   │    │    │                        FK  identity_provider_id
   │    │    │                        UQ (identity_provider_id, provider_subject)
   │    │    │
   │    │    └─────────────────── magic_link_token
   │    │                             FK  user_id
   │    │                             UQ  token_hash
   │    │
   │    └──────────────────────── local_credential
   │                                  FK  user_id  UQ
   │                                  password_hash, lockout fields
   │
   └───────────────────────────── user_role
                                       PK (user_id, role_id)
                                       FK  user_id → app_user
                                       FK  role_id → role

┌─────────────────────────────┐       ┌─────────────────────────────┐
│ role                        │       │ identity_provider           │
│─────────────────────────────│       │─────────────────────────────│
│ PK  id              serial  │       │ PK  id                 uuid │
│ UQ  name            text    │       │ UQ  provider_type      text │
│     values: agency,         │       │     name, issuer, client_id │
│             contractor      │       │  *  secret_reference        │
└─────────────────────────────┘       │  *  hosted_domain           │
                                      │     enabled, created/updated│
                                      └─────────────────────────────┘

  Access: agency and contractor users both see the full agency.
  Only contractor users may create/update/delete resources.
