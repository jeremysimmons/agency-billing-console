AIB database schema (PostgreSQL) — slim ClickUp billing prep
Sources: backend/Aib.Migrations/Migrations/*.sql (run via ./scripts/run-migrations)
Enum-like columns stored as text (PascalCase, matching C# enums).
PK = primary key · FK = foreign key · UQ = unique · * = nullable

================================================================================
OVERVIEW
================================================================================

  agency ──┬── client ──┬── project   (you define — not ClickUp lists)
           │            └── task      (ClickUp sync + manual prep cols)
           │
           └── last_clickup_sync_*

  clickup_container   (space / folder / list lookup; refreshed on sync)

  task upsert key: clickup_url (or clickup_task_id)
  client link: clickup_folder_id (from ClickUp folder on sync/import)

================================================================================
3. APP LOGIC
================================================================================

Missing data (needsAttention) when any of:
  - project_id is null
  - bill is null
  - bill = yes and billable_hours is null or 0
  - invoice_label is null or blank

Sync (POST /api/clickup/sync):
  1. Upsert clickup_container from ClickUp API hierarchy
  2. Page team tasks (assignee + date_created_gt filter)
  3. Upsert task by clickup_url; update API cols only on existing rows
  4. Auto-create/update client from clickup_folder_id + folder name

CSV import (POST /api/clickup/import-csv):
  One-shot load of sheet export; upsert by url; merges all columns.
